# 플랫폼별 발행용 원고

같은 글을 플랫폼 3곳에 맞게 각각 최적화해둔 폴더입니다. 각 파일은 해당 플랫폼 에디터에 그대로 붙여넣으면 되는 상태입니다.

## 폴더 구성

```
blog-exports/
└─ 오디세이/
   ├─ 네이버블로그.txt    → 텍스트 붙여넣기 + 사진 4장 직접 첨부
   ├─ 티스토리.html       → HTML 모드에 붙여넣기 (이미지 자동 로드)
   └─ 구글블로거.html     → HTML 보기에 붙여넣기 (이미지 자동 로드)
```

## 플랫폼별 차이

| | 네이버 블로그 | 티스토리 | 구글 블로거 |
|---|---|---|---|
| 주 수익원 | 애드포스트 + 쿠팡파트너스 | 애드센스 + 쿠팡파트너스 | 애드센스 |
| HTML 붙여넣기 | 불가 (텍스트만) | 가능 | 가능 |
| 이미지 | 직접 업로드 필요 | 자동 (외부 URL 사용) | 자동 (외부 URL 사용) |
| 광고 삽입 | 애드포스트 자동 | 본문 내 수동 배치 가능 | 자동 배치 지원 |
| 검색 유입 | 네이버 검색 | 다음·구글 | 구글 |

## 이미지에 대해

티스토리·블로거용 HTML은 이미지를 `https://danielmoon82.github.io/moon/posts/images/` 주소로 불러옵니다. 홈페이지가 살아있는 한 계속 정상 표시되며, 별도 업로드가 필요 없습니다. 더 안전하게 하려면 각 플랫폼에 이미지를 직접 업로드해서 주소를 바꿔도 됩니다.

네이버 블로그는 외부 이미지 삽입이 제한되므로, `naver-blog-posts/06-영화-오디세이-정보총정리/images/` 안의 PNG 4장을 직접 첨부해야 합니다.

## 같은 글을 3곳에 올려도 되나

원문을 그대로 복사하면 중복 콘텐츠로 검색 노출이 불리해질 수 있습니다. 그래서 세 파일은 제목·도입부·구성이 조금씩 다르게 작성돼 있습니다. 추가로 각 플랫폼에서 문단 순서를 바꾸거나 본인 감상을 한두 문단 덧붙이면 더 안전합니다.

# 네이버 블로그 포스팅 세트

각 폴더/파일 구성:

- `0N-제목.md` : 본문 원고 (제목, 태그, 메타설명, 본문, 이미지 삽입 위치 표시)
- `0N-제목/images/1_cover.png` : 대표(썸네일) 이미지
- `0N-제목/images/2_checklist.png` : 핵심 요약 리스트 이미지
- `0N-제목/images/3_highlight.png` : 강조 포인트/비교 이미지
- `0N-제목/images/4_summary.png` : 마무리 요약 이미지

## 네이버 블로그에 올리는 순서

1. 네이버 블로그 글쓰기 화면을 엽니다.
2. `.md` 파일의 제목을 블로그 제목란에 복사합니다.
3. 본문을 위에서부터 순서대로 복사해 붙여넣습니다. 🖼️ 표시가 나온 지점마다 해당 이미지를 사진 첨부 버튼으로 넣어주세요 (마크다운 문법(#, **, |표|)은 네이버 에디터에서 자동으로 안 바뀌니, 소제목은 에디터의 '소제목' 스타일로, 굵게는 Ctrl+B로 별도 지정해주세요).
4. 하단 "추천 태그"를 태그란에 그대로 입력합니다.
5. "수익화 메모"에 안내된 위치에 배너를 추가합니다.
6. "함께 쓰면 좋은 아이템" 섹션의 `[쿠팡파트너스 링크 삽입: ...]` 자리에 아래 방법으로 실제 링크를 넣습니다.

## 쿠팡파트너스 링크 넣는 법

각 글마다 3~4개 추천 상품(검색 키워드 + 문구 예시)을 정리해뒀습니다. 실제 URL은 계정별 추적코드가 포함돼야 해서 아래처럼 직접 발급받아 넣어주세요.

1. partners.coupang.com 로그인
2. 상단 검색창에 글에 적힌 키워드(예: "가습기") 검색
3. 원하는 상품 선택 → **링크 생성(공유하기)** 클릭
4. 생성된 URL을 복사해서 `[쿠팡파트너스 링크 삽입: ...]` 자리에 그대로 붙여넣기
5. 네이버 블로그 정책상 문제 없도록, 각 글 상단에 있는 고지문("이 포스팅은 쿠팡 파트너스 활동의 일환으로...")은 반드시 그대로 유지해주세요 (쿠팡파트너스 필수 표기 사항).

## 이미지 스타일

생활정보 꿀팁 시리즈로 통일감을 주기 위해 포스팅마다 고유 색상(주황/파랑/초록/남색/핑크)을 적용했고, 하단에 "생활정보 꿀팁" 워터마크를 넣어 시리즈물임을 표시했습니다.
